# Superstore Sales Data Analysis Using Excel

## Project Overview

This project focuses on **data cleaning, analysis, and visualization of Superstore sales data using Microsoft Excel**. The objective is to transform raw sales data into a clean and structured dataset and generate meaningful business insights through Excel analysis and visualizations.

## Project Aim

The main aim of this project is to:

- Clean and prepare the Superstore sales dataset.
- Analyze sales, profit, quantity, and discount.
- Identify important trends and patterns.
- Create meaningful visualizations using Excel.
- Generate useful business insights from the data.

## Dataset Description

The **Sample - Superstore** dataset contains information about orders, customers, products, sales, discounts, profit, shipping, and geographical regions.

Important columns include:

- Order ID
- Order Date
- Ship Date
- Ship Mode
- Customer ID
- Customer Name
- Segment
- Country
- City
- State
- Region
- Product ID
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

## Data Cleaning

The following data-cleaning activities were performed:

1. Checked the dataset structure and column names.
2. Checked for missing values.
3. Checked for duplicate records.
4. Verified and corrected data types.
5. Formatted date columns correctly.
6. Checked numerical columns such as Sales, Quantity, Discount, and Profit.
7. Checked categorical columns for consistency.
8. Removed unnecessary data where required.
9. Prepared the final cleaned dataset for analysis.

## Analysis and Visualization

The cleaned dataset was analyzed using Microsoft Excel.

The analysis includes:

- Sales by Category
- Sales by Sub-Category
- Profit by Category
- Profit by Sub-Category
- Sales by Region
- Profit by Region
- Sales trends over time
- Top customers
- Top products
- Quantity analysis
- Discount analysis
- Sales and Profit comparison

## Dashboard

The Excel dashboard provides an overview of Superstore sales performance, including
total sales, total profit, total orders, customers, regional sales, monthly sales,
top products, and top customers.


## Key Insights

- Total sales generated were approximately 2.30M.
- Total profit generated was approximately 286K.
- The South region recorded the highest sales among the four regions.
- Technology had the highest average sales among the three categories.
- The dashboard identifies the top 10 products and top 10 customers based on sales.
- Monthly sales show changes in performance across the year, with higher sales in the later months.


## Conclusion

This project demonstrates an end-to-end **sales data analysis workflow using Microsoft Excel**, starting from raw data cleaning and continuing through analysis, visualization, and insight generation. The project provides a clear understanding of sales and profitability patterns and demonstrates practical Excel skills for data analysis.
